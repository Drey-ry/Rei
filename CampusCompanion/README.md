# Campus Companion - MAD2 Laboratory Exercise 1

This is a complete Storyboard-based UIKit project for the Campus Companion welcome-screen exercise.

## Open and run

1. Open `CampusCompanion.xcodeproj` in Xcode on a Mac.
2. Select an iPhone Simulator, such as **iPhone SE (3rd generation)**.
3. Press **Command + R**.
4. Tap **Get Started** and confirm that the subtitle changes to **Let's get started!**.
5. Repeat on **iPhone 15 Pro Max** to verify the Auto Layout behavior.

## Included requirements

- Storyboard interface using UIKit
- Bold 28-point `Campus Companion` title
- 16-point `Your Campus, In Your Pocket` subtitle
- Aspect-fit image view with a campus SF Symbol supplied by code
- Centered `Get Started` button
- `@IBOutlet` named `titleLabel`
- `@IBOutlet` named `subtitleLabel`
- `@IBAction` named `getStartedTapped`
- Auto Layout constraints for safe-area margins, spacing, centering, and fixed image size
